2. 主要用来干什么

开会的时候它在旁边听着，会后给你一份文字记录和摘要——全程在你自己的电脑上跑，不上云。

它解决的是一个很多人已经在用商业产品解决、但一直不放心的问题：会议记录工具好用，可你的会议内容全传到别人服务器上了。涉及客户、合同、内部决策的会议，很多公司根本不允许。

它做三件事：

  1. 实时转录：一边开会一边出文字，用的是 Parakeet 或 Whisper 模型
  2. 区分说话人：谁说了哪句（这一条要看清楚，见下面的提醒）
  3. 生成摘要：接本地跑的 Ollama 模型来总结，所以摘要这一步也不出本机

支持 macOS 和 Windows，用 Rust 写的。

典型场景：客户访谈、内部评审、一对一沟通——任何"内容不能外传但又想留记录"的会议。

两个必须先说清楚的事：

一、说话人区分这个功能，得看清楚版本。 GitHub 简介里写着有说话人分离，但 README 正文里说的是：说话人分离计划放在 PRO 版，时间是"六月中"。这两处对不上。如果你就是冲"区分谁在说话"来的，装之前一定要先确认社区版到底有没有——这可能是它和免费替代品之间最关键的差别。

二、它有商业版。 项目本身是 MIT 开源的，但背后是一家公司（Zackriya Solutions），有付费的 PRO 版，卖更高精度、高级导出、自定义摘要流程和团队功能。这不是坏事——有公司养着的开源项目往往活得更久——但你要知道免费版和付费版的边界在哪，尤其是上面那条。

3. 为什么会火

它戳中了什么痛点

AI 会议记录工具已经很成熟了（Otter、Fireflies 这些），但它们有一个共同的前提：你的会议录音要上传到他们的服务器。

对个人来说这只是隐私顾虑；对企业来说这经常是一票否决——客户会议、法务会议、涉及合同和内部决策的会议，合规部门根本不会批。于是很多团队的现状是：明知道有好工具，但不能用，只能手写纪要。

Meetily 就是冲这个空档来的：同样的能力，全部在你自己的机器上跑。

为什么是它赢了

它把整条链路都本地化了——转录本地跑、摘要也本地跑（接 Ollama）。很多号称"隐私优先"的工具只做到转录本地，摘要还是调云端 API，那等于没做。

而且它能接进 Zoom、Teams、Google Meet，不用改变开会习惯。

大家在夸什么

真的不上云、能装在 Mac 和 Windows 上、开源可自托管、有公司在持续维护。

大家在骂什么（这段最重要，而且难得的是团队自己承认）

长会议的摘要质量会下降。 一小时以上、或者话题很多的会议，输出明显不如云端模型。

这一条是 Meetily 团队自己在文档里写的，评测也复述了。一个团队愿意主动写出自己产品的短板，这本身值得加分——但你要据此调整期望：

  • 半小时的一对一：够用
  • 两小时的多方评审：摘要只能当初稿
  • 有评测明确建议：客户会议、法律会议、重要决策会议要格外谨慎，AI 摘要必须人工复核，尤其是行动项和责任人

你还要留心一件事

它有商业版。项目是 MIT 开源的，社区版承诺永久免费，但 PRO 版卖更高精度、自定义摘要模板、高级导出、自动会议检测、自托管部署和团队功能。其中说话人区分（谁说了哪句）在 README 里被列为 PRO 版计划中的功能，但 GitHub 简介里又写着有——装之前务必确认社区版到底有没有这一条。

meetily 的位置很清楚：它是这批里唯一一个"完整产品"，其他几个是零件。你当然可以用 whisper.cpp 转录 + 自己写脚本调 Ollama 总结，但那是个项目，不是个工具。

什么时候该选它

  • 你要的就是"开完会有一份纪要"，而且内容不能上云 → 选 meetily，这是最直接的答案，没有第二个。
  • 但如果"分辨谁说了哪句"是硬需求 → 先停一下。README 里把说话人分离列为 PRO 版计划中的功能，而 GitHub 简介里写着有。这两处对不上，装之前一定要确认社区版有没有。 如果没有，而你又必须要，那只能自己上 whisperX（能力最强，但要写代码）。
  • 你的会议大多超过一小时 → 降低期望。团队自己承认长会议摘要质量会掉。可行的折中：让它做转录，摘要自己另找模型处理——转录是它的强项，摘要是它的弱项。
  • 会议是中文的 → FunASR 的中文识别更成熟，但它不是成品工具。这是个真实的权衡：要产品完整度就选 meetily，要中文准确率可能得自己拼。
  • 你只想偶尔转一个录音文件 → 用不着它，whisper.cpp 一条命令就够。

一句话：meetily 的价值是"完整"，不是"最强"。 每个单项都有更强的对手，但没有一个能一次给你全套且不上云。

你亲测时重点看这几点

  1. 社区版到底有没有说话人分离（最该先验，因为它决定这工具对你成不成立）。装上开一个两人会议，看它能不能分出谁是谁。文档自相矛盾的地方，实测一次就能定论。
  2. 中文会议的转录和摘要质量。所有评测都是英文场景。用一段真实的中文会议录音跑一遍——中文的口语、打断、专业术语，是最容易露馅的地方。这块是空白。
  3. 长会议到底掉多少。团队承认一小时以上会掉，但没人量化过。同一段两小时录音，让它总结一次，再手动切成四段分别总结，对比一下——这个实验能直接告诉观众怎么用才对。
  4. 免费版和 PRO 版的实际差距。除了功能列表，精度到底差多少？值不值那个钱？
  5. 接 Zoom/Teams 顺不顺。宣称能集成，但实际是要装插件、还是靠录系统声音？这决定了它在真实会议里好不好使。
