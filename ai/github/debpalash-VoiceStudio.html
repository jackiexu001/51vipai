2. 主要用来干什么

在自己电脑上克隆声音、给视频配音、做有声书——对标 ElevenLabs，但完全本地、不要账号、不要 API key、没有用量限制。

作者是 Palash Debnath，前身叫 OmniVoice-Studio，现在改名 VoiceStudio。它是个桌面软件，不是给程序员用的库（但也提供接口）。

它能干的事：

  • 克隆一个人的声音：只需要 3 到 15 秒的干净参考音频
  • 给视频配音：把一种语言的视频配成另一种语言
  • 做有声书：长文本批量生成
  • 语音输入 / 转文字：反过来把语音转成文本
  • 设计声音：不是克隆现有的人，而是造一个新音色

装了 16 个语音合成引擎 + 11 个语音识别引擎，可以随时切换；号称支持 646 种语言的合成（实际覆盖和质量取决于你选哪个引擎）。

除了桌面界面，它还提供本地 REST 接口、兼容 OpenAI 格式的音频 API，以及一个 MCP 服务——也就是说可以直接接进你的 AI 工作流，这一点对你可能比图形界面更重要。

有三件事在动手前必须知道，我按重要性排：

一、许可证是 AGPL-3.0，不是宽松许可证。 简单说：如果你把它接进一个对外提供服务的产品里，AGPL 会要求你把你自己的代码也开源。自己用没问题，商用前务必先想清楚。（下载的模型还各自遵守自己的条款。）

二、它明确标注还在 beta 阶段。 README 顶部有醒目警告：正经干活请用发布版，main 分支随时会变。

三、克隆是"零样本"的，喂更多音频没用。 这一点反直觉但很重要：它不是拿你的音频去训练模型，而是把那一小段当作"提示"。所以喂 2 小时录音并不会让它更像你——超过那个短窗口的部分根本不会被用到。想提升效果，方向是"换更干净的 15 秒"，而不是"给更多素材"。

硬件上：有独显最好，但显存不到 8 GB 时它会自动把合成挪到 CPU 上跑，不用你配置；纯 CPU 也能跑，只是慢。

3. 为什么会火

它戳中了什么痛点

想给视频配音、做有声书、克隆一个声音，主流选择是 ElevenLabs——效果好，但两个问题绕不开：一是按月付费（据报道 5 到 330 美元/月不等），二是你的音频要传到别人服务器上。

对个人创作者来说第一条是持续出血；对企业和涉密场景来说第二条直接一票否决。"能不能在自己电脑上跑"是个真需求，不是伪需求。

为什么是它赢了

同类的本地方案大多是给程序员用的命令行工具或 Python 库，普通人装不起来。VoiceStudio 做成了桌面软件，Windows / macOS / Linux 都有安装包，下载即用。

而且它把一堆开源引擎打包在一起（16 个合成 + 11 个识别）而不是绑定一个——你可以随时换。语言覆盖上号称 646 种，有报道拿它跟 ElevenLabs 的 32 种作对比。

大家在夸什么

隐私、零成本、语言覆盖广、可定制。有报道总结得比较中肯：

语音克隆和配音上，两者质量在多数场景下相当。ElevenLabs 赢在打磨过的云端 API 和现成音色库，VoiceStudio 赢在隐私、成本、语言覆盖和可定制性。

你要留心的地方

  1. AGPL-3.0 许可证。 这是我认为最该先看的一条——自己用无所谓，接进对外服务的产品会触发开源义务。
  2. 明确的 beta 状态。 README 顶部自己挂着警告。
  3. 改过名。 前身 OmniVoice-Studio，网上两个名字的资料混在一起，而且还存在同名的第三方仓库，别下错。
  4. 我没有找到成规模的负面评测。 现有报道基本都是介绍性质、偏正面。这说明深度使用者还不多——效果到底怎么样，尤其中文效果，公开资料回答不了。

这张表最值钱的是"最近更新"和"许可证"两列，两列都是查接口得来的，博客文章不会告诉你：

  • coqui-ai/TTS 已经死了——2024 年 8 月最后一次更新。很多老教程还在推荐它，别再入坑。
  • OpenVoice 近一年半没动。
  • fish-speech 没有声明许可证——效果再好，商用前也得先问作者。

什么时候该选它

  • 你要的是"打开就能用"的桌面软件，不想碰 Python → 选 VoiceStudio（或 pyvideotrans）。这是它最大的价值，其他大多数是给程序员用的库。
  • 你专门做中文视频的翻译配音 → 优先 pyvideotrans。国产、专注这一件事、中文场景打磨得更久，VoiceStudio 是全能选手但每一项未必最深。
  • 你要接进自己的程序里 → 看 F5-TTS（MIT，学术质量）或 fish-speech（效果好但许可证是坑）。
  • 你要的是变声不是配音（比如把自己的录音变成另一个音色）→ 只有 RVC，上面其他几个都不做这个。
  • 无论如何别选 coqui-ai/TTS——虽然它星最多、教程最多，但已经停更两年。这是"高星 ≠ 能用"最典型的例子。

给你的一条实际建议：VoiceStudio 是 AGPL-3.0，如果你只是自己做视频素材，完全没问题；但如果哪天想把它包进一个对外的产品或服务，这条许可证会要求你开源自己的代码。真到那一步，F5-TTS（MIT）是更安全的地基。

你亲测时重点看这几点

  1. 中文克隆效果到底怎么样（最值得验，也最可能出内容）。它号称 646 种语言，但所有公开评测都是英文场景。用你自己的声音录 15 秒中文，让它读一段中文，听听像不像、有没有洋腔。这个结论全网没有。
  2. "3–15 秒就够"是不是真的。它是零样本克隆，多喂音频没用——那 5 秒和 15 秒差别大吗？换一段更干净的音频有多大提升？验这个能直接告诉观众该怎么录素材。
  3. 在你的 Mac 上多快。它对 Apple 芯片有专门优化，但没人给过具体数字：一段 1000 字的文本，生成要多久？
  4. beta 到底有多不稳。README 自己挂了警告。连续跑几个小时的有声书任务，会不会崩、会不会漏字。
  5. 和 pyvideotrans 比，中文视频配音谁更好。这两个是最直接的竞争关系，而且都是桌面软件、都能装。同一个视频各跑一遍，这个对比是最有传播力的内容。
