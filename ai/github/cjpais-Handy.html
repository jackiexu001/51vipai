2. 主要用来干什么

按住一个快捷键说话，松开后文字直接出现在你正在打字的地方。 全程在你自己的电脑上完成，一个字都不上传。

它不是"又一个转录工具"，而是一个语音输入法——你在写邮件、写代码注释、填表单，随时按住快捷键说两句，文字就落进去了。用完即走，没有界面挡在中间。

工作流程简单到几乎没有：

  1. 按住快捷键（也可以设成按一下开始、再按一下结束）
  2. 说话
  3. 松开，它自动转写
  4. 文字粘贴进你当前所在的任何输入框

技术上：先用一个叫 Silero 的模块把静音段掐掉，再交给识别模型。模型有两类可选——Whisper（有显卡时会用显卡加速）或者 Parakeet V3（专门为 CPU 优化，能自动判断你说的是什么语言）。Windows、macOS、Linux 都能装，macOS 可以直接 brew install --cask handy。

它的定位很特别，值得单独说一句。 作者在 README 里写了一句我认为很坦诚的话：

Handy 不想成为最好的语音转文字应用——它想成为最容易被 fork 的那一个。

翻译成人话：它有意保持简单，好让你自己改。 所以如果你想找一个功能最全的听写软件，它可能不是；但如果你想要一个能读懂、能改、能长期自己维护的底子，它就是冲这个来的。

一个实际提醒：Homebrew 和 winget 上的安装包不是官方维护的（README 里明确说了）。想要最新版，从官网或 GitHub 发布页下载更稳妥。

3. 为什么会火

它戳中了什么痛点

语音输入这件事，系统自带的不好用、准确率一般；好用的（Wispr Flow 这类）要订阅、要账号，而且你说的每一句话都传到别人服务器上。对于要口述邮件、口述代码注释、口述会议纪要的人来说，这既是钱的问题，也是隐私的问题。

它是怎么来的（这个起源故事我觉得值得一说）

作者 CJ Pais 是因为手指受伤、打字疼，才动手做了这个东西。这解释了它为什么长这样：不追求功能多，只追求"按住、说、松开"这一件事顺到极致——因为作者自己每天都要用。

什么时候火的

2025 年 6 月发到 Hacker News，Show HN 那个帖子拿了 247 分，评价压倒性正面。大家夸的点很集中：按住说话这个交互足够简单、开源、纯本地。后来还有第二次讨论。

为什么是它赢了

同类里要么是给程序员用的命令行工具（普通人装不起来），要么是收订阅的商业软件。它卡在中间：桌面软件的易用度 + 开源的自由度 + 零成本。

而且它把"简单"当成设计目标而不是妥协。作者那句"不想做最好的，想做最容易被 fork 的"，是一种很少见的自我克制。

大家在夸什么

  • 零遥测——有评测专门扫过它有没有埋分析 SDK，结果是一个都没有
  • 没有付费层、没有订阅、没有字数限制、没有账号，靠 GitHub 赞助和捐款维持
  • 模型选择多：跨 13 个家族的 65 个语音模型（Whisper、Parakeet、Moonshine 等）

大家在骂什么

有一篇评测的标题直接叫「免费、离线，以及 7 个粗糙的地方」——说明它确实有毛刺。这是我这次找到的唯一一篇系统性挑毛病的文章，值得你动手前先读一遍。

另外要注意：Homebrew 和 winget 上的包不是官方维护的，版本可能滞后。

这些经常被混为一谈，其实解决的是完全不同的问题，我按"你想干嘛"拆开：

  • 想边说边打字（语音输入法）→ Handy
  • 想转录一个已有的音频文件 → whisper.cpp（命令行）
  • 想记会议 → meetily
  • 想知道谁说了哪句 → whisperX
  • 做中文内容 → FunASR
  • 想把文字变成语音 → VoiceStudio（方向相反）

什么时候该选它

  • 你想要的是"口述代替打字"这个日常习惯 → 选 Handy，没有更合适的。它是这批里唯一把"语音输入法"这件事做成开箱即用桌面软件的。
  • 你要批量处理一堆音频文件 → 用 whisper.cpp，命令行更适合写脚本跑一夜。
  • 你的场景就是开会 → meetily 更对症，它多做了摘要和会议集成。
  • 你需要区分说话人 → Handy 不做这个，得上 whisperX。
  • 你主要说中文 → 这是我建议你实测的重点：Handy 用的是 Whisper 和 Parakeet，中文效果没人正经测过；而 FunASR 是专门为中文打磨的。如果 Handy 的中文识别不行，那它对你的价值会打对折。

一句话：Handy 赢在"日常习惯"这个定位，而不是识别能力。 它底下用的还是 Whisper——识别能力和其他几个是同一批模型，差别在交互设计。

你亲测时重点看这几点

  1. 中文口述准不准（最值得验，也最可能出内容）。所有评测都是英文场景。用中文说一段带专业术语的话（比如夹杂英文缩写的技术描述），看它怎么处理中英混说、怎么加标点。这个结论全网没有。
  2. 那"7 个粗糙的地方"到底是哪 7 个。有一篇评测专门列了它的毛病，你实际用一周，验证哪些是真问题、哪些无所谓。这是唯一一篇批评文章，值得当作对照。
  3. 延迟有多长。按住说完松开，多久文字才出来？这个数字决定它能不能真的替代打字，但没人给过。
  4. 和系统自带的听写比，到底强在哪。macOS 自带听写是免费的，你得回答"为什么要多装一个"——这是观众一定会问的问题。
  5. 换模型的差别有多大。它支持 13 个家族 65 个模型，Whisper Turbo 和 Parakeet V3 在你机器上分别多快、多准？选哪个是最实际的问题。
